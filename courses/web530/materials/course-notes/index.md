# About the Course

Welcome to Cross‑Platform App Development with React Native, Expo, and Firebase. This course introduces the fundamentals of building mobile applications using React Native, one of the most widely used frameworks for modern mobile development. Students will also collaborate on a group project, applying their skills to design and develop a functional mobile application.

The course covers the fundamentals of React and React Native, including how to set up a development environment and install the required tools. It also introduces Expo, a suite of tools and services that streamlines the process of building, testing, and deploying React Native apps.

In addition, the course explores Firebase, a robust backend platform that provides services such as data storage, authentication, and real‑time updates. By the end of the course, students will have the knowledge and hands‑on experience needed to build and deploy mobile applications using React Native, Expo, and Firebase.
