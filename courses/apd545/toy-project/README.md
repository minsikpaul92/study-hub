# CafeOrder 토이 프로젝트 (APD545)

APD545 강의 Week 1~13 내용을 한 주에 한 단계씩 쌓아서, 마지막에 하나의 카페 주문 시스템(JavaFX + Guice + SQLite)을 완성하는 프로젝트예요.

- `weekNN/GUIDE.md`: 그 주에 할 일 (왜 하는지, 따라하기, 직접 해보기, 시험 포인트)
- `weekNN/CafeOrder/`: 그 주 단계가 끝난 시점의 정답 코드 (IntelliJ에서 Maven 프로젝트로 열기). 막혔을 때만 열어 보기.

| Week | 단계 | 상태 |
| --- | --- | --- |
| 1 | 콘솔 MVC 뼈대 (MenuItem, CafeView, CafeController) | ✅ [가이드](week01/GUIDE.md) |
| 2~13 | 상속/인터페이스 → 컬렉션 → JavaFX → MVC → 대화상자, DI → 여러 화면, Guice → SQLite(JDBC) → ... | 준비 중 |

실행: IntelliJ → File > Open → `weekNN/CafeOrder` (pom.xml 있는 폴더) → `CafeApp`의 `main` 옆 ▶.
